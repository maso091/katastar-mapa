# Katastarska mapa — darovni ugovor 18/71

Čestice iz darovnog ugovora (K.O. Klanac 310778, Kruščica 310794, Gornje Pazarište 310727).

Podaci: DGU/OSS ATOM servis (javni download DKP-a po katastarskoj općini).

- `fetch-parcels.js` — skida GML, filtrira čestice, reprojicira EPSG:3765 → WGS84
- GitHub Actions automatski pokreće build i commita `map.html` + `parcels.geojson`
- Otvori `map.html` lokalno ili preko https://raw.githack.com za pregled online
